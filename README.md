# Escape the Haunted School

## Overview

Escape the Haunted School is a text-based adventure game developed in Python using Object-Oriented Programming (OOP).

The player wakes up alone inside a haunted school after dark. To escape, the player must explore different rooms, collect useful items, avoid dangerous ghosts, and find the Master Key before reaching the exit.

This project was created for a Software Engineering assessment to demonstrate Python programming, Object-Oriented Programming, and software development skills.

---

# Features

- Text-based gameplay
- Object-Oriented Programming (OOP)
- Multiple rooms to explore
- Inventory system
- Collectable items
- Ghost encounters
- Health system
- Win and lose conditions
