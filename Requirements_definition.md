# Requirements Definition

## Aim

The aim of this project is to create a text-based adventure game using Python and Object-Oriented Programming (OOP). The player must explore a haunted school, collect important items, avoid ghosts, and find the Master Key to escape safely.

---

# Functional Requirements

## Player

- The player must be able to enter their name.
- The player must have health and an inventory.
- The player must be able to move between rooms.

## Rooms

- The game must contain multiple connected rooms.
- Each room must display its name and description.

## Inventory

- The player must be able to collect items.
- Items must be stored in the player's inventory.

## Ghosts

- Ghosts must appear in selected rooms.
- Ghosts can reduce the player's health.

## Game Progress

- The player wins by finding the Master Key and escaping the school.
- The player loses if their health reaches zero.

---

# Non-Functional Requirements

## Performance

- The game should respond quickly to player commands.

## Usability

- Commands should be easy to understand.
- Instructions should be displayed clearly.

## Reliability

- The game should run without crashing during normal gameplay.

## Maintainability

- The code should be organised into classes and methods.
- The code should include comments where appropriate.

---

# Constraints

## Technology

- Python must be used.
- The project must use Object-Oriented Programming.
- GitHub must be used for version control.

## Resources

- Only free software and tools may be used.

## Time

- The project must be completed by the assessment due date.

---

# Acceptance Criteria

The project will be considered successful if:

- The player can move between rooms.
- Items can be collected.
- The inventory functions correctly.
- Ghost encounters work correctly.
- The player can win or lose the game.
- The program demonstrates Object-Oriented Programming concepts.
